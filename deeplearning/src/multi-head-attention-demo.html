设定一个能口算的迷你例子

为了把每个数字都算清楚，我们把规模缩到最小：1 句话、3 个 token，每个 token 用 4 维词向量表示（d_model=4），2 个头（h=2），于是每个头分到 d_head = 4 ÷ 2 = 2 维。

约定：X 的每一行是一个 token 的词向量 —— 第 1 行是 t₁，第 2 行是 t₂，第 3 行是 t₃。偏置 b 取全 0（代码里本来就用 zeros 初始化，先不扰动它），W 全取小整数，方便口算验证。

看 W 上的颜色：Wq、Wk、Wv 的前两列（青色）只服务头 1，后两列（赭色）只服务头 2 —— 一个 (4×4) 大矩阵，其实是两个 (4×2) 小矩阵横向拼在一起。这就是"多头"能共用一次矩阵乘法的原因。

下面是本文拆解的 PyTorch 代码（即你的实现），①~⑦ 标记对应页面各节：

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0          # d_model 必须能整除头数
        self.h = n_heads
        self.d_head = d_model // n_heads       # 每个头的维度 = 2

        self.W_q = nn.Parameter(torch.randn(d_model, d_model) * 0.02)
        self.W_k = nn.Parameter(torch.randn(d_model, d_model) * 0.02)
        self.W_v = nn.Parameter(torch.randn(d_model, d_model) * 0.02)
        self.W_o = nn.Parameter(torch.randn(d_model, d_model) * 0.02)
        self.b_q = nn.Parameter(torch.zeros(d_model))
        self.b_k = nn.Parameter(torch.zeros(d_model))
        self.b_v = nn.Parameter(torch.zeros(d_model))
        self.b_o = nn.Parameter(torch.zeros(d_model))

    def _split_heads(self, T):                 # 传入 (B, n, d_model)
        B, n, _ = T.shape
        return T.view(B, n, self.h, self.d_head).transpose(1, 2)
        # 拆头 → (B, h, n, d_head)

    def forward(self, X):                      # X: (B, n, d_model)
        B, n, _ = X.shape
        Q = self._split_heads(X @ self.W_q + self.b_q)          ① 投影 + 拆头
        K = self._split_heads(X @ self.W_k + self.b_k)          ①
        V = self._split_heads(X @ self.W_v + self.b_v)          ①

        scores = Q @ K.transpose(-2, -1) / self.d_head ** 0.5   ②③ 打分 + 缩放
        attn = torch.softmax(scores, dim=-1)                    ④  归一化
        out = attn @ V                                          ⑤  加权求和

        out = out.transpose(1, 2).reshape(B, n, self.h * self.d_head)  ⑥ 拼头
        return out @ self.W_o + self.b_o, attn                  ⑦ 输出投影
①

投影 + 拆头

(1,3,4) → (1,2,3,2)

Q = X·Wq + bq　→　_split_heads　→　(B, h, n, dhead)

这一步做两件事：投影 —— 每个 token 的 4 维向量乘 Wq，变换到"查询空间"（K、V 同理换到"被查空间""内容空间"）；拆头 —— 把 4 维结果切成 2 段、每段 2 维，分给两个头。

交互提示：把鼠标悬停在结果矩阵的任一数字上，会点亮参与计算的来源 —— 青色 = 左因子的对应行，赭色 = 右因子的对应列。后面每个乘法图都可以这样玩。

逐格看：Q 的第 1 行 = X 第 1 行 [1,0,1,0] 与 Wq 各列的点积。例如 Q₁₄ = 1×1 + 0×0 + 1×0 + 0×0 = 1。

拆头：view(B,n,h,d_head) 先把每个 token 的 4 维切成 2 段（逻辑形状 (1,3,2,2)，不复制数据）；transpose(1,2) 再交换第 1、2 维 → (1,2,3,2)，让"头"成为第 2 维 —— 每个头独立拿到全部 3 个 token。

注意 Q 的列怎么变成两个头的行块：青色两列（头 1 的子空间）→ Q头1；赭色两列（头 2 的子空间）→ Q头2。行不变，仍然是 3 个 token。

②③

打分 + 缩放：Q·Kᵀ ÷ √d_head

(1,2,3,2)×(1,2,2,3) → (1,2,3,3)

scores = Q·Kᵀ ÷ √dhead，　即　sij = qi·kj ÷ √2

打分的含义：query i 和 key j 点积越大 = token i 越该关注 token j。K 先转置成 (2,3)，Q(3×2)·Kᵀ(2×3) 得到 (3×3) 的分数矩阵 —— 行是 query，列是 key。

为什么除以 √d_head，而不是 √d_model？
点积是 d_head 项乘积之和。若 q、k 的各分量独立、均值 0、方差 1，则 q·k 的方差 = d_head（这里 = 2）。维度越大，分数越分散，softmax 会逼近 one-hot、梯度消失。除以 √d_head 把分数方差拉回 ~1，softmax 保持"软"。
每个头是在自己的 d_head 维子空间里打分的，所以除的是 √2；写成 √d_model 是最常见的错误。
④

Softmax：分数 → 注意力分布

(1,2,3,3) → (1,2,3,3)

attn = softmax(scores, dim=-1)，　wi = exᵢ ÷ Σj exⱼ

dim=-1 是最后一维 = key 维：对每一行（每个 query）独立做归一化，输出每行和恰好为 1 —— 可以读作"query t₁ 把 100% 的注意力分给 k₁/k₂/k₃ 的比例"。

头 1：颜色深浅 = 权重大小

头 2：颜色深浅 = 权重大小

指数的作用：放大差距，让分数最大的 key 拿走大头（头 1 的 q₁ 行里 k₂ 分数 2.83 最高 → 拿走 76.8% 的注意力）。而头 1 的 q₃ 行三个分数完全相等（都是 1.41），softmax 给出完全均匀的 1/3, 1/3, 1/3 —— 分数相同则一视同仁。
⑤

加权求和：attn·V

(1,2,3,3)×(1,2,3,2) → (1,2,3,2)

out = attn·V，　即　outi = Σj wij·vj

每个 query 按注意力权重，把所有 token 的 v 加权混合 —— 这就是"信息聚合"：t₁ 的新表示主要由 t₂ 的内容构成（权重 0.77）。

因为每行权重和为 1，输出是 V 各行的凸组合，永远不会跑出 V 张成的范围。例证：V头1 的第 2 维恰好全是 1 → out头1 第 2 维精确等于 1；V头2 第 1 维全是 1 → out头2 第 1 维恒为 1。
⑥

拼头：transpose + reshape，顺序不能反

(1,2,3,2) → (1,3,4)

现在每个头的输出是 (1,2,3,2)：头在外面、token 在里面。拼接的目标是让每个 token 的两个头的片段重新拼回一个 4 维向量。

transpose(1,2)：让同一 token 的各头片段相邻　→　reshape(1,3,4)：拍平成 d_model

反例：跳过 transpose 直接 reshape 会怎样？
(2,3,2) 按内存顺序拍平 = 先排头 1 的全部 3 个 token、再接头 2 的 —— 得到下面的"错位矩阵"：第 1 行是头 1 的 t₁、t₂ 硬拼，头 2 的信息直到第 2 行才出现，token 与头完全错乱。
另外：transpose 之后张量在内存里不连续，不能再用 .view()（会报错），要用 .reshape()（必要时自动拷贝）或 .contiguous().view()。
⑦

输出投影：让两个头交换信息

(1,3,4)×(4,4) → (1,3,4)

输出 = 拼接·Wo + bo

拼完后每个 token 回到 4 维，但前 2 维只来自头 1、后 2 维只来自头 2 —— 两个头还没说过话。Wo 做一次线性组合，把各头子空间的信息混合起来，并把维度对齐交给下一层（通常随后与残差相加）。

返回值 (out, attn)：out (1,3,4) 送给下一层；attn (1,2,3,3) 是 2 张 3×3 注意力热力图（上面 ④ 里那种），专供可视化和分析 —— 行是 query、列是 key。
✓

易错点清单 & 形状速查

  1. 缩放用 √d_head，不是 √d_model。每个头在自己的 d_head 维子空间里打分（代码 self.d_head ** 0.5）。
  2. 拆头顺序：先 view(B,n,h,d_head)（把 d_model 切成 h 段）再 transpose(1,2)。顺序反了，每个头拿到的维度就是跨头混排的。
  3. softmax 的 dim=-1：沿 key 维归一化，每行是一个 query 的分布、和为 1。写成 dim=0 会沿 token 方向归一化，语义全错。
  4. 拼头顺序：必须先 transpose(1,2) 再 reshape；直接 reshape 会把头与 token 错位（见 ⑥ 的反例）。transpose 后不连续，用 reshape 而非 view。
  5. 大矩阵 = 多个小矩阵：W_q (d_model×d_model) 等价于 h 个 (d_model×d_head) 小矩阵横向拼接，一次乘法算完所有头 —— 高效的实现方式。
  6. attn 的形状 (B,h,n,n)：h 张 n×n 热力图，行 = query、列 = key，是调试/可视化注意力的第一手材料。
